
# UI方針

ISS TRACKERとWORLD WEATHERに倣い、暗い紺色の背景と青緑系のアクセントを使います。3D地形を主役にし、地名や数値を読みやすくするため操作UIは独立したパネルへ配置します。

- PC：左を大きな3D表示、右を操作パネルとする。ヘッダーとフッターの区切り線は左右端まで伸ばさない。
- スマートフォン：3D表示を先、設定パネルを下に配置。地図がタッチ操作でき、ページは縦スクロール可能。
- 初期状態：標高カラー、1倍の強調、日本全域を表示。強調倍率は0〜10倍で、0倍では平面化する。外部背景地図は使用しない。
- 操作パネル：視点操作（「視点をリセット」「正面視」）、強調倍率、クリック地点の標高。回転・ズーム・パンは3D地形上の直接操作で行う。
- 「視点をリセット」は初期の俯瞰斜め視点に戻す。「正面視」は南側から地形を見る。標高データと強調倍率は変更しない。
- 冒頭の大きな見出し「日本列島の地形を、立体で見る。」は表示しない。
- 標高表示はデータの実数値。表示倍率をかけた標高値を情報欄へ出してはならない。
- 取得中はタイル枚数と進捗バーを示し、取得に失敗したら失敗理由と再読み込み案内を示す。
- 画面上の3D操作：ドラッグで回転、ホイール・ピンチでズーム、パンで移動。
- フッターに国土地理院の出典表示とリンクを残す。これは装飾ではなく利用条件への対応。右端にはGitHubリポジトリへのリンクを追加し、スマートフォンでも右寄せを維持する。
- 色だけに依存せず、ボタンの選択状態は枠線・ラジオ表示・aria-pressedでも伝える。
