
# JAPAN GEOMETRY 仕様

## 目的と表示範囲

- 日本列島の標高を実データから3D可視化する。建物・植生・海底地形は今回の対象外。
- 初期範囲：経度 122〜154°E、緯度 20〜47°N。日本国外の周辺地域も含む矩形表示。
- Web Mercator（XYZタイル）に沿って地理院DEMを取得する。
- 位置・高度に関してダミーデータ、ランダム生成は使用しない。

## データソース

- 国土地理院 `demgm_png/{z}/{x}/{y}.png`：全球版 DEMGM。zoom 7（日本周辺は144タイル）を使用（公開範囲 zoom 0〜8）。
- DEMは 256×256 RGB PNG。24bitの値 `x = R*65536 + G*256 + B`、`x < 0x800000` は `x/100` m、`x > 0x800000` は `(x-0x1000000)/100` m、`x = 0x800000` は欠損。
- 無効画素と未取得タイルを区別する。取得済みタイル内の無効画素は海域などのため海面（0m）の表示頂点として扱い、隣接する陸地を含む海岸線の三角形は描画する。ただし無効画素に実測標高を割り当てず、地点選択時も標高を取得したことにはしない。未取得タイルを含む三角形は生成せず、他のタイルの値で補完しない。
- 海面のみから成る三角形は描画せず、別の海面プレーンに任せる。
- 海域・0m以下の標高は水平面としてレンダリング。海底起伏は表示しない。
- 描画メッシュは 640×640 の格子（410,881頂点）。Web Mercator座標の各頂点から地理座標に戻し、DEMのピクセル値を取得する。
- 表示倍率は初期値1倍、0〜10倍（1刻み）。0倍では全頂点をy=0にした平面用ジオメトリへ切り替え、1〜10倍では元メッシュのyスケールのみ変更する。0倍でもUV・クリック判定を維持し、地点の標高表示は倍率によらずDEMから復元したメートル値。
- 地表の表示色は標高による頂点カラーのみ。地理院標準地図やOpenStreetMapのラスタタイルは読み込まない。

## ユーザー操作

- Three.jsのOrbitControlsで回転・パン・ズーム。ドラッグとクリックは移動距離で区別する。
- 「視点をリセット」で起動時の位置 (8, 22, 29)・原点への注視に復帰する。OrbitControls.saveState/resetにより拡大縮小・移動も戻す。
- 「上面視」で地形の真上 (0, 39, 0.001) にカメラを配置し、北（-Z）を画面上方とする地図型の俯瞰表示へ切り替える。OrbitControlsのminPolarAngleを0にして上面視を許可する。微小な+Z偏差はカメラのupベクトルの特異点回避用。いずれの操作でも標高倍率は変更しない。
- 地形の選択はRaycasterで交点UVを求め、緯度経度を逆投影し、同じDEMデータから標高を取得。

## 非対応・制約

- 地形の切り抜き、建物の立体表示、等高線、山頂標高の厳密な測定、地物の検索は対象外。
- グリッドと標高タイルのサンプリングによる近似のため、富士山の描画上の頂点やクリック標高は公称標高と異なり得る。
- DEMタイルはzoom 7の144枚のまま。メッシュ分割を320×320から640×640へ増やすため、頂点数は約4倍になり、端末性能に応じた描画・構築負荷が増加する。背景地図タイルは取得しない。
- WebGL・Canvas 2D・外部ホストへのHTTPS通信が必要。専用バックエンド・APIキー・ユーザーデータ保存は不要。
